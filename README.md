# buying and selling website with Next.js

[![Next.js](https://img.shields.io/badge/Framework-Next.js-black?logo=next.js&logoColor=white)](https://nextjs.org)


## 🧰 Technologies Used

- Tailwind CSS
- Material UI (MUI)
- bcriptjs
- zod
- jsonwebtoken
- leaflet
- lucide-react
- mongoose
- zustand

---

## 📥 Installation Steps

1. Clone the repo:
   - git clone https://github.com/alireza-rezaei22/bazarbin.git 
2. Navigate into the project directory and install packages:
    - cd /bazarbin
    - npm install
3. Start project:
    - npm run dev
